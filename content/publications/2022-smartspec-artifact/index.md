abstract: |-
  This artifact abstract is a guideline for SmartSPEC, a simulator for
  generating customizable smart space datasets using semantic models of spaces,
  people, events and sensors. SmartSPEC is based on two main components:
  (i) Scenario Learning which produces metamodels of events and people using
  input seed data; and (ii) Scenario Generation which uses SmartSPEC data to
  generate a realistic smart space dataset. SmartSPEC provides three modes of
  operation to generate synthetic data varying in the level of user
  involvement/automation.
